Make one like this

An agent picks a video they love and gets a new one in the same style, on their own topic.

The plan

Where it lives

  • Create → Video / Reel → Script Source gets a third tile, Like a video I love, next to AI writes it and My Content/Forwarded in.
  • The same choice goes on the Camera/Teleprompter tab as a chip, so the teleprompter script follows the video too.

What the agent does

  • Uploads the video, or pastes a YouTube link. For Instagram or TikTok, they save the video and upload it.
  • Says or types their topic, then taps Read the video. It takes about 30 seconds.

What comes back

  • What we picked up: hook, length, pace, order, tone, captions, music and shape.
  • A new script on the agent's topic, built the same way, in the normal script box so they can edit it.
  • The matching settings already chosen: shape, length, captions, music mood and b-roll pace. Each one can still be changed.
  • Nothing renders until Spark It, and the render costs one video, the same as today.

Rules

  • It never copies their footage, face, voice, music or exact words. The script is written fresh.
  • Videos up to 3 minutes and 200 MB. The file goes straight to storage, so the 4.5 MB limit doesn't apply.
  • Open to every plan. Up to 20 reads a month per account, with no limit for admins. Each read costs us a few cents.
  • The uploaded video is deleted from Gemini right after the read. We keep only the "what we picked up" notes.
